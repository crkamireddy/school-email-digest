Config Builder

Answer a few questions about your family's schools and where you want digests to go. You'll get a config.yaml file to put in your school-email-digest folder.

🔒 Everything stays in this browser tab. Nothing you type is sent anywhere.

1 Schools and classes

Add each school that sends you email, and the class (or classes) your kids are in there. The digest keeps schoolwide news plus anything for these classes, and skips things aimed at other grades.

2 Where email comes from and where digests go

Both of these need to be set up first. See README.md, Part 1, steps 3 and 6.

3 How you'll run it

The digest keeps a small log of what it's already sent so it doesn't repeat itself. This decides where that log lives.
